# charity: water Landing Page Redesign

A responsive redesign of the charity: water landing page, built with plain HTML and CSS for a beginner web design assignment. Based on a Canva mockup, the page features a navy-and-cream layout, a six-photo CSS slideshow, and a "GIVE TODAY" button linking to charity: water's donation page.

Open `index.html` in a browser to view the page. No installation or build tools are required.
